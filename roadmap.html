Product Roadmap

A patch-first improvement plan focused on quality and usability, without fixed delivery dates.

Latest Patch Focus (2.3.1)

  • Keep weapon lists aligned with the current global game state.
  • Maintain clean, consistent patch notes language across the site.
  • Improve clarity in management and changelog UI surfaces.

Core Reliability and Safety

  • Silent autosave with robust session recovery prompts.
  • Stronger validation for imported and persisted data.
  • Safer destructive actions with restore-friendly workflows.

Strategy Workflow Enhancements

  • Named strategy library for managing multiple plans.
  • Reusable marker presets for recurring map scenarios.
  • Smarter roster import mapping for ambiguous source files.
  • Quick filters for role, team, and weapons in Manage Players.

UX and Accessibility Polish

  • Cleaner modal hierarchy and more readable long-form content.
  • Consistent focus styles and keyboard navigation behavior.
  • Responsive layout tuning for desktop, tablet, and mobile workflows.
  • Hotkey help that always reflects real, active shortcuts.

Export, Review, and Communication

  • Higher quality export options for sharing and review.
  • Action history improvements for better strategy iteration.
  • Patch note standards that clearly document what shipped.
This roadmap is intentionally commitment-light on dates. Items are prioritized by impact, stability, and community value rather than fixed deadlines.
